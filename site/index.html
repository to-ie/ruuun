A running adventure for beginners.

Log each run, aim for your next mission and move through a story of four worlds. Walking counts, and every run moves you on.

Download for Android

Free. Android 8.0 or newer. No account needed.

On a computer? Open ruuun.t-o.ie on the Android phone you want to install it on, and tap the button there.

How it works

Four things to keep an eye on. None of them ever tells you off.

Your next mission

A distance to aim for

Beat it and the next one is a bit further. Had a hard day? It eases off. You can always make it easier.

Your weekly goal

1, 2 or 3 days a week

You pick. Each week also has an optional side quest, like running at a park or trying a new route.

The story

Twelve chapters, four worlds

From Rookie Woods to Planet Zoom. Every day you run moves the story on, whatever the distance.

Badges

147 to collect

For showing up, going a bit further, trying new places, saying how it felt and coming back after a break.

Installing

ruuun! is not on the Play Store, so it installs straight from this page.

New to ruuun!

  1. On your Android phone, tap Download for Android.
  2. Open the downloaded file. If Android asks, allow your browser to install apps.
  3. Open ruuun! and set up your plan. It takes a minute.

New versions show up as a banner at the top of the app. Tap Update, then Install. Your runs and badges stay as they are.

Moving from the 1.0 beta

Version 1.1 is signed differently, so it cannot install over the beta. Move across once:

  1. In the beta, open Settings and tap Export progress. Save the file somewhere you can find it.
  2. Uninstall the beta.
  3. Install the new version from this page.
  4. In Settings, tap Import progress and pick the file you saved.

After this, updates install over the top with no extra steps.

For grown-ups

ruuun! is made for one young runner on a family phone. Walking is part of running, and rest days help. Stop and tell an adult about any pain, dizziness or feeling unwell.

The code is open on GitHub.

  • No account and no sign-in.
  • No ads, no shop and nothing to buy.
  • No location tracking. Runs are typed in by hand.
  • Runs stay on the phone unless you export a backup yourself.
  • The app only goes online to check GitHub for a new version of itself.
